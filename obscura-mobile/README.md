# Obscura Mobile — متصفحك الخفي على هاتفك 📱

تطبيق أندرويد **مجاني 100٪** (Kotlin) يحوّل هاتفك إلى **لوحة تحكم وعارض حي** لأي خادم
[Obscura](https://github.com/h4ckf0r0day/obscura) — محرك المتصفح الخفي المكتوب بلغة Rust.

> **مهم:** Obscura نفسه «محرك بدون واجهة» (headless) — يعمل على جهاز/سيرفر، وليس تطبيقًا
> تُفتحه. هذا التطبيق هو **ذراعك على الهاتف**: يشاهد الصفحة حيًّا، يفتح روابط، ينفّذ
> JavaScript، ويلتقط لقطات وPDF — كل ذلك عبر بروتوكول Chrome DevTools Protocol.
> الخادم يعمل على هاتفك نفسه (عبر Termux) أو على أي جهاز/سيرفر تملكه. **لا حاجة لأي
> اشتراك أو خدمة مدفوعة إطلاقًا.**

## ⬇️ التنصيب المجاني (الطريق الأسرع)

1. حمّل ملف الـ APK من [Releases](https://github.com/mrsalimeki/OBS/releases) —
   ابحث عن إصدار `obscura-mobile-v1.0` وحمّل `obscura-mobile-v1.0.apk`.
   (البناء يتم تلقائيًا ومجانيًا عبر GitHub Actions عند كل تحديث للكود.)
2. على أندرويد: الإعدادات ← التطبيقات ← «تثبيت تطبيقات مجهولة المصدر» ← سمح للتطبيق
   الذي تفتح به الملف (المتصفح/المدير).
3. افتح الملف `.apk` وفعّل التثبيت.

## 🚀 شغّل الخادم مجانًا — 3 طرق

### الطريقة 1 — كل شيء داخل هاتفك (الموصى بها، تعمل حتى بدون إنترنت بعد التثبيت)

المشروع الرسمي يدعم Termux صراحةً (أدواته تبحث عن `proot-distro`). الخطوات:

1. ثبّت [Termux](https://f-droid.org/packages/com.termux/) من **F-Droid** (مجاني؛
   نسخة Google Play قديمة ولا تعمل).
2. داخل Termux:
   ```bash
   pkg update
   pkg install proot-distro curl
   proot-distro install ubuntu
   proot-distro login ubuntu
   ```
3. داخل Ubuntu (تعمل داخل هاتفك):
   ```bash
   curl -LO https://github.com/h4ckf0r0day/obscura/releases/latest/download/obscura-aarch64-linux.tar.gz
   tar xzf obscura-aarch64-linux.tar.gz
   ```
4. شغّل الخادم:
   ```bash
   ./obscura serve --port 9222
   ```
5. افتح **Obscura Mobile**: العنوان `127.0.0.1` والمنفذ `9222` **بدون توكن**
   (التوكن اختياري على محارة الوصول المحلي). اضغط «اتصال». ✅

> ملاحظة: اترك نافذة Termux مفتوحة (الخادم يعمل داخلها). إن أُغلق تم، أعد تشغيل
> الأمر نفسه.

### الطريقة 2 — جهازك على نفس شبكة الواي فاي

```bash
OBSCURA_CDP_TOKEN="$(openssl rand -hex 32)" obscura serve --host 0.0.0.0 --port 9222
```

- في التطبيق: العنوان = عنوان الجهاز على الشبكة المحلية (مثل `192.168.1.20`)،
  المنفذ `9222`، والتوكن = النص الذي طبعه الأمر (مطلوب للتواصل خارج المحارة المحلية).
- إن لم تعرف عنوان جهازك: الإعدادات ← الشبكة والواي فاي ← تفاصيل الشبكة الحالية.

### الطريقة 3 — سيرفر مجاني في السحابة

حساب [Oracle Cloud Free Tier](https://www.oracle.com/cloud/free/) يمنحك دائمًا
جهازًا صغيرًا مجانيًا (Always Free). شغّل عليه الأمر نفسه في الطريقة 2، ثم استخدم
عنوان السيرفر العام في التطبيق **مع التوكن**.

> ⚠️ أمان: لا تُعرّض المنفذ `9222` على الإنترنت **بدون** توكن — Obscura نفسه يرفض
> الإقلاع على عنوان غير محلي إذا لم تُضبط `OBSCURA_CDP_TOKEN` (32 بايت على الأقل).

## ✨ مزايا التطبيق

- **بث حي** للصفحة (لقطات متدرجة: سريعة أثناء التغيّر، بطيئة عند السكون — نفس
  استراتيجية أداة `live-view` الرسمية).
- شريط عنوان + تنقّل (رجوع/تقديم/إعادة تحميل) + مؤشر تحميل.
- **تبويبات**: تبويب جديد، التبديل بين الصفحات المفتوحة، إغلاق.
- **وحدة تحكم (Console)**: سجل `console.log` من الصفحة + استثناءات JS + حقل
  «تنفيذ JavaScript» (مثل DevTools).
- **حجم العرض**: هاتف (390×844) أو كمبيوتر (1280×800) — محاكاة أبعاد جهاز.
- **لقطة شاشة** (PNG) و**تصدير PDF** — يُحفظان على الهاتف ويمكن مشاركتهما مباشرة.
- شاشة اتصال ذكية (تتذكر آخر خادم) + استعادة تلقائية عند انقطاع الاتصال.
- واجهة عربية داكنة، بدون صلاحيات مفرطة (إنترنت فقط).

## 🔧 بناء المشروع بنفسك (مجاني)

1. ثبّت [Android Studio](https://developer.android.com/studio) (مجاني).
2. File ← Open ← اختر هذا المجلد `obscura-mobile/`
   (إن طلب Android Studio إنشاء ملفات Gradle wrapper فوافق؛ سيحمّلها تلقائيًا).
3. اضغط أيقونة ▶ (Run) أو Build ← Build APK… — ينتج `app/build/outputs/apk/debug/app-debug.apk`.

المتطلبات: أندرويد 8 (API 26) فأحدث، Kotlin 1.9، AGP 8.5، OkHttp 4.

## 🔒 ملاحظات الأمان

- التطبيق يتصل عبر `http://` (CDP عادي) — هذا مقصود؛ على الشبكة المحلية لا مشكلة،
  وعلى السحابة اعتمد على التوكن.
- التوكن يُحفظ محليًا على جهازك فقط (SharedPreferences) ولا يُرسل لأي جهة ثالثة.
- Obscura يحظر بالاتصال بالشبكات الخاصة (SSRF) افتراضيًا؛ إذا أردت فتح صفحة محلية
  من التطبيق (خادم تطوير على نفس الجهاز…) مرّر `--allow-private-network` عند تشغيل
  `obscura serve`.
